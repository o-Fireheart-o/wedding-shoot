agent.md 목표(봉스튜디오 사진 30장 이상, 외부 캐주얼 10건 이상)는 두 쪽 모두 충족했다. 다만 아래 주의사항에 적은 한계가 있어, 숫자를 그대로 ‘인기 순위’로 읽으면 안 된다.

핵심 결론

  1. 모던·미니멀이 압도적 1위다. 순백 룸·계단·아치 복도·블랙 배경·우드 합판벽 계열이 컷 33장 사실 / 세션 21건 추정으로 가장 많다. 언론·제휴 소개문의 “모던한 실내배경”과 일치한다.
  2. 2위는 야외 숲·가든. 세트장 바로 옆 숲길·잔디밭을 쓰고, 노을 잔디밭(선셋씬)이 이 계열의 대표 컷이다. 컷 20장 / 세션 13건.
  3. “엔틱”은 기대보다 얇다. 제휴사 소개문은 “클래식하고 엔틱함”을 강점으로 내세우지만, 공개 포트폴리오에서 그렇게 분류되는 것은 캔들 롱테이블(야간) 계열 컷 5장 / 세션 3건뿐이다. 주의 엔틱을 원하면 세트 운영 여부부터 물어야 한다.
  4. 3·4위 차이는 유의하지 않다. 플라워·로맨틱과 자연광·창가는 컷 수가 각 14장으로 동률이고 세션 수만 8 대 7로 갈린다.
  5. 캐주얼은 봉스튜디오 안에도 있다. 잔디밭 풍선·피켓 컷이 세션 4건 확인된다. 다만 티셔츠·청바지 수준의 캐주얼은 확인되지 않아, 외부 레퍼런스(§4)를 따로 모았다.

주의사항

1. 봉스튜디오 실제 후기는 0건이다. 네이버 블로그는 크롤러 차단, 공식 인스타그램 @bongstudio_은 로그인 월, 웨딩크라우드 후기 6건은 개별 글 주소가 노출되지 않아 HOLD 7건으로 남겼다. 이 보고서가 근거로 쓴 것은 스튜디오가 선별해 올린 공식·제휴 포트폴리오뿐이다. 실제 결과물이 샘플과 얼마나 같은지는 이 자료로 알 수 없다.

2. 주소 표기가 두 가지다. 공식 홈페이지 푸터는 경기도 하남시 미사동로40번길 124-27, 2024년 12월 언론 기사는 경기도 하남시 미사동 203-7로 적는다. 둘 다 하남시 미사동이지만 현재 촬영장이 어디인지는 직접 확인해야 한다(§5).

3. 세션 수와 계절은 추정이다. 세션은 카메라 프레임 번호 간격 300 기준으로 묶은 하한 추정치이고, 계절은 사진 속 식생·광질에서 읽었다. 촬영 일자는 어디에도 공개되어 있지 않다. 커플 수·예약 건수는 산출하지 않았다.

4. 계절·날씨로 결과가 달라진다. 제휴사 페이지에 “앨범의 성격상 날씨나 계절에 따라 촬영의 컨셉이 샘플과 달라질 수 있음”이 명시되어 있다. 야외 세트(운동장·정원·미니결혼·베일)가 직접 영향을 받는다.

5. §4 외부 레퍼런스는 봉스튜디오 촬영이 아니다. 18건 전부 재현 가능 여부가 확인 필요이고, 카페·스포츠·취미 무드는 확보하지 못했다. 5건은 매거진 기사 1건에서 나와 독립 출처 수가 사례 수보다 적다.

2봉스튜디오 인기 콘셉트 순위표

확인 사례 수 기준 내림차순. 확인 컷 수는 사실, 세션 수는 추정이다. HOLD·EXCLUDE 항목은 집계에서 전부 제외했고, 타 스튜디오 레퍼런스(§4)는 한 건도 섞이지 않았다.

  3. 야외 세트에서 달리기·춤 같은 동적 포즈가 가능한가요?
