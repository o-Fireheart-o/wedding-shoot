### 1.2 '사례' 단위 정의 — 사실과 추정의 경계 (중요)

제휴 포트폴리오 이미지 파일명에 `세트명 + 카메라 원본 파일명`이 그대로 남아 있다(예: `정원1R1A3051-1`, `통창HO__2654-22`, `작은창KWON0859-1`). 여기서 읽어낼 수 있는 것과 읽어낼 수 없는 것을 구분한다.

| 단위 | 내용 | 구분 |
| --- | --- | --- |
| 컷 | 파일명이 다르면 서로 다른 사진이다. | **사실** |
| 세트 | 파일명 앞부분이 세트명이다. | **사실** |
| 프레임 | `1R1A`, `JUN_`, `KWON`, `HO__`, `GYU_`, `L1xx` 6종 카메라 바디의 프레임 번호가 그대로 남아 있다. | **사실** |
| 세션 | 같은 바디에서 프레임 번호 간격이 300 이내면 같은 촬영 회차로 묶었다. | **추정** |
| 커플 수 | 산출하지 않았다. | **산출 불가** |

- 세션 군집은 실제로 한 촬영이 여러 세트를 도는 패턴과 맞아떨어진다. 예: 세션 `S04`는 `베일 → 통창 → 작은창 → 정원`(`1R1A3345 / 3353 / 3569 / 3716` 등), 세션 `S10`은 `반반 → 주간파티 → 합판벽`(`1R1A8218 / 8249 / 8338 / 8412`)으로 이어진다. 즉 **서로 다른 파일 ID가 곧 서로 다른 촬영 회차는 아니다.**
- 따라서 세션 수 **46건은 하한 추정치**다. 간격 기준(300프레임)을 좁히면 늘고 넓히면 줄어든다. 세션과 커플이 1:1인지도 확인할 수 없다.
- `KWON` 접두사가 공식 사이트 대표자명 **권기봉**과 이니셜이 일치하지만, 촬영자 매칭은 **추정**이다.
- 공개 자료만으로 예약 건수·커플 수는 알 수 없어 추정하지 않았다 (agent.md 수집 방법 4항).

### 1.3 핵심 결론

- **반복 확인됨**: 정돈된 실내 무배경·구조물 계열(**모던·미니멀**)이 세션 21건 / 컷 33장으로 1위, **야외 숲·가든**(노을 잔디밭·가든)이 세션 13건 / 컷 20장으로 2위다. 제휴·언론 소개문("모던한 실내배경과 야외촬영", "200평 세트장 + 바로 옆 숲길")과 일치한다.
- **기대와 다른 점**: 제휴사 소개문은 "클래식하고 엔틱함"을 강점으로 내세우지만, 공개 포트폴리오 표본에서 앤틱 가구·짙은 톤의 고전 실내로 분류할 수 있는 것은 캔들 롱테이블(`야간`) 계열 **세션 3건 / 컷 5장뿐**이었다. 엔틱 콘셉트를 원하면 현재 세트 운영 여부를 스튜디오에 직접 확인해야 한다.
- **계절 주의**: 제휴사 페이지에 "앨범의 성격상 날씨나 계절에 따라 촬영의 컨셉이 샘플과 달라질 수 있음"이 명시되어 있다. 야외 세트(`운동장` 노을씬, `정원`, `미니결혼`)는 계절·우천 영향을 직접 받는다.
- **출처 주의**: 공식 인스타그램 `@bongstudio_`은 로그인 월로 원문 확인이 불가했고, 유사·동명 상호 계정이 최소 6개 존재한다(부록 B). 인스타그램 기반 사례는 전부 HOLD 처리했다.

**표본 수·조사 기간**: 위 순위는 **2026-09-20 하루** 동안 확인한 **컷 94장 / 세트 29개 / 추정 세션 46건** 표본에 근거한다. 순위 판단의 1차 근거는 세션 수이고, 컷 수는 교차 확인용이다. 두 기준은 **1·2위(모던·미니멀 → 야외 숲·가든)와 최하위(클래식·엔틱)에서 일치**하고, 3~4위만 갈린다 — 컷 수로는 플라워·로맨틱 세트와 자연광·창가가 각 14장으로 동률이고, 세션 수로는 플라워 8건 대 창가 7건이다. 즉 **3위와 4위 사이의 차이는 유의하다고 보기 어렵다.** 공개 포트폴리오는 스튜디오가 선별해 올린 것이므로 **실제 예약 비중과는 다를 수 있다.**

### 3.1 분류 판단 메모 (사실 / 추정 구분)

- 세트명은 이미지 파일명에 보존된 값 그대로다. (사실)
- `클업`은 세트명이 아니라 **클로즈업 컷**을 뜻하는 것으로 보여 6개 카테고리 집계에서 뺐다. (추정)
- `한화`는 파일명 표기를 그대로 옮긴 것이다. (사실) 확인한 사진은 레드·오렌지 컬러 배경 화보이며, agent.md의 "컬러 배경 또는 장식" 기준에 따라 플라워·로맨틱 세트로 분류했다. (판단)
- `성벽`·`개선문`은 이름과 달리 실제 사진에서 **화이트 아치 + 그린·화이트 꽃 대형 장식**이 지배적이어서 플라워·로맨틱 세트로 분류했다. (사실 기반 판단)
- `하트`·`포스터`는 드레스를 입었지만 잔디밭에서 풍선·피켓을 들고 노는 상호작용이 주된 요소라 캐주얼·라이프스타일로 분류했다. (판단)
- 계절 표기는 사진 속 식생·광질에서 읽은 것이며, **촬영 일자는 어디에도 공개되어 있지 않다.** (추정)
- 각 사진은 1개 주 카테고리만 부여했다 (agent.md 분류 체계 단서).
